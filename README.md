🏦 Bank Management System (Java)

A simple, console-based Bank Management System built using Java. This project demonstrates basic banking operations and fundamental Java programming concepts.

✨ Features

- 👤 Create a bank account
- 🔐 Login using account details and password
- 💰 Check account balance
- 💵 Deposit money
- 💸 Withdraw money
- 📋 View account details

🛠️ Technologies Used

- Language: Java
- Library: "java.util.Scanner"

🚀 How to Run

Prerequisites

- Java JDK installed on your device

Steps

1. Clone this repository:
   
   git clone https://github.com/exeleviackerman-web/Bank-Management-System.git

2. Open the project directory:
   
   cd Bank-Management-System

3. Compile the Java file:
   
   javac BankManagementSystem.java

4. Run the program:
   
   java BankManagementSystem

📚 Concepts Practiced

- Classes and objects
- Constructors
- User input using "Scanner"
- Conditional statements and "switch"
- Loops
- Basic banking operations

⚠️ Current Limitations

- Account information is not permanently stored.
- The program is a beginner-level demonstration, not a real banking application.
- Passwords and account details are handled without production-grade security.

🔮 Future Improvements

- Support multiple accounts
- Store account data permanently using files or a database
- Add stronger input validation
- Improve login security
- Add transaction history
